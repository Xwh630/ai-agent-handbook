## 🧩 趋势观察

### 1. MCP 无状态化：协议核心简化

MCP 2026-07 版本转为完全无状态核心，移除了 `Mcp-Session-Id` 头，并已捐献给 Linux Foundation。这意味着：
- Server 部署更简单，天然支持 Serverless
- Client 实现更轻量，连接即会话
- 与 HTTP 缓存、负载均衡的兼容性更好

> 📖 手册[第 11 章](../chapters/11-mcp.md)已同步更新，新增无状态章节与 SDK 迁移指引。

### 2. 上下文工程（Context Engineering）崛起

Anthropic 最新研究显示：通过结构化笔记 + 子 Agent 隔离策略，研究类任务评测得分提升 **90.2%**。

一次轮次的 token 构成大致为：
- 历史消息：~46%
- 检索内容：~24%
- 工具定义：~18%
- 系统提示：~9%
- 用户问题：~3%

**优化空间最大的是工具定义和历史消息**，而不是模型本身。

### 3. A2A v1.0 GA 在即

Google 牵头的 Agent-to-Agent 协议预计 11 月发布 v1.0 GA。Agent Card 格式、任务委派与结果交换机制已基本稳定。与 MCP 的分层边界也日益清晰：

```
MCP  → Agent ↔ 工具/数据（已稳定，事实标准）
A2A  → Agent ↔ Agent（标准化中，v1.0 在即）
```

- **字节 DeerFlow** 72K⭐，长任务 SuperAgent harness 持续迭代
