# 📡 Agent Radar — AI Agent 圈每周动态

> **Agent Radar** 是《AI Agent 实战手册》的周刊栏目：每周一期，追踪 Agent 圈最新项目、框架版本、论文、协议与玩法。
>
> 为什么做这个栏目？Agent 领域变化以"周"为单位，手册的章节讲透原理，Radar 负责让你不掉队。

## 🎯 栏目定位

- **每周更新**：每周五发布（遇大新闻加更）
- **宁缺毋滥**：每期精选 10 条左右，拒绝信息垃圾
- **手册联动**：重要趋势会沉淀为正式章节（如第 25 章 Harness Engineering 就由雷达观察孵化）
