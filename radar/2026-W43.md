## 🔥 头条：从"能跑"到"敢上线"，中间隔着一张体检单

这一周我在整理手册第 25 章（Harness Engineering）的反馈时，发现一个反复出现的提问：

> "我知道该有任务边界、上下文压缩、失败恢复……但**我怎么知道我的项目现在缺哪一根？**"

这就是"方法论"和"工具"之间的缝。五根柱子写在文章里人人都懂，但**没有人会拿文章去对照自己的 800 行 main.py**。

于是我们把第 25 章做成了一条命令：

```bash
uvx agent-handbook doctor .
```

它静态扫描你的 Python 代码，对五根柱子各打 0–2 分，每一分都给出**具体到 `文件:行号` 的证据**：

```
支柱        得分      状态          证据
--------------------------------------------------------------------
任务边界      ●●      ✅ 扎实        main.py:86, main.py:89
上下文管理     ○○      ❌ 缺失        —
状态持久化     ●○      ⚠️ 薄弱        main.py:180
失败恢复      ○○      ❌ 缺失        —
权限体系      ○○      ❌ 缺失        —
```

### 为什么"体检"比"再写一章"更重要

| | 写第 32 章 | 做 doctor |
|---|---|---|
| 受益的人 | 已经在读的人 | **任何一个有 Agent 项目的陌生人** |
| 结果形态 | 文字 | **一张能截图的分数** |
| 传播方式 | 需要别人愿意读 | 打分本身就是话题（"我只有 3 分？"） |
| 可复用性 | 一次性 | 每次改代码都能重跑 |

> 这也是本期想说的核心：**内容让人理解，工具让人行动。** 一个"能给你打分"的东西，比十篇"讲得很清楚"的文章更容易被记住、被转发、被写进别人的 CI。

### 两个实用开关

```bash
handbook doctor . --md            # 输出 Markdown 表格，直接贴进 issue / README
handbook doctor . --exit-code     # 低于 6 分返回非零码，接进 CI 当门禁
```

`--md` 是给「提 issue」用的：如果你发现某个开源 Agent 项目缺了柱子，跑一下，把表格贴过去，比写一句"你的项目不够健壮"有用一百倍。

## 🧩 趋势观察

### 1. 评测从"跑分"变成"上线前检查"

Benchmark 回答的是"模型多聪明"，而团队真正需要的答案是"我这一版能不能发"。这两个问题之间差着一整个工程层。第 30 章（评测体系）里提到的 **EDD（Eval-Driven Development）** 正在被更具体地拆解：不是一张总分榜，而是一组**每个都要通过的检查项**。

体检清单和评测集正在合流——**它们都是"上线门禁"的不同侧面**。

### 2. "协议战争"退潮，交付质量成为新战场

x402 / AP2 / Agent Identity（第 29 章）还在推进，但社区讨论的重心明显从"用哪个协议"转向"接完之后怎么保证不出事"。当基础设施趋同，**差异化只能来自交付质量**。

### 3. 单文件 Agent 正在变成一种负担

越来越多项目从"一个 main.py 跑通"演进到"12 个文件互相调用"，而 Harness 的五根柱子恰恰是**在单文件阶段最容易被省略、在多文件阶段最贵**的东西。上下文管理和失败恢复尤其如此——它们在 demo 里永远是 0 成本，在生产里是全部成本。

## 📄 论文与评测

- **Harness 视角的失效归因**：把 Agent 失败分成"模型能力不足 / 上下文腐坏 / 状态丢失 / 无恢复路径"四类，这个分类法比笼统的"hallucination"更有指导性——对应第 25.3、25.4、25.5 节。
- **长会话下的上下文衰减**：多轮工具调用后，早期关键指令的权重下降速度快于预期。第 27 章的压缩策略正是对这件事的工程回应。

## 💡 本周一个值得思考的问题

> **如果你的 Agent 项目现在被公开打分，你敢把分数贴出来吗？**

大多数人的答案是不敢。但这个"不敢"本身，就说明了 Harness 不是加分项，而是**及格线**。

欢迎到 [Discussions](https://github.com/Xwh630/ai-agent-handbook/discussions) 聊聊：你给自己项目打多少分，最缺哪一根？
