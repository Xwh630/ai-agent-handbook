## 🔥 本周头条：Harness 工程成为 2026 年最大共识

业界正在形成一个明确共识：**Agent 的竞争力越来越不取决于底层模型，而取决于"驾驭工程"（Harness Engineering）**——任务边界设计、上下文管理、状态持久化、失败恢复、权限体系。同样的模型，不同的 Harness，落地效果可以差出数量级。

**三个佐证**：

| 项目 | Stars | 说明 |
|------|-------|------|
| [superpowers](https://github.com/obra/superpowers) | 272K⭐ | Agentic skills 框架 + 开发方法论，登顶 Agent 类榜首 |
| [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) | 231K⭐ | "与你一起成长的 Agent"：持久记忆 + 自进化技能 |
| [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) | 137K⭐ | 直接把 Harness 写进名字的 SWE-bench 开源框架 |

## 🧩 趋势观察

### 1. Agent Skills 生态爆发

Anthropic 的 Agent Skills 范式（把领域知识打包成可复用的"技能包"）正在形成生态：superpowers 本质就是 skills 框架，各类 skills marketplace 开始涌现。**编写和组合 Skill，正在成为比写 Prompt 更值钱的技能。** 手册后续将新增 Skills 实战章节。

### 2. Computer Use 走向生产

[browser-use](https://github.com/browser-use/browser-use)（115K⭐）、UI-TARS（39K⭐）代表的"让模型直接操作界面"路线持续升温。评测体系同步转向：从问答 benchmark 走向 GAIA、METR 长任务等**端到端任务成功率**导向。能稳定完成 30 分钟以上多步任务，比单轮惊艳更重要。

### 3. 协议分层格局清晰

Agent 协议生态已从"一个协议解决所有问题"演进为明确分层：

```
MCP    → Agent ↔ 工具/数据（事实标准，公开 Server 超 10,000 个）
A2A    → Agent ↔ Agent（Google 牵头，2026 年发布 v1.0）
AG-UI  → Agent ↔ 前端界面（流式事件）
AP2    → Agent ↔ 支付/授权（Agentic Commerce 的基础设施）
```

> 📖 MCP 已有[第 11 章](../chapters/11-mcp.md)；A2A 姊妹篇筹备中，敬请期待。

### 4. 个人助理 Agent 成为最大单品类

OpenClaw（385K⭐）登顶开源 Agent 榜——"住在你已有聊天软件里的个人 AI 助手"验证了 PMF。Hermes Agent（228K⭐）紧随其后。自托管、跨平台消息接入、持久记忆是这类产品的三要素。

### 5. 国产力量

- [bytedance/deer-flow](https://github.com/bytedance/deer-flow)（72K⭐）：字节长任务 SuperAgent harness
- [TauricResearch/TradingAgents](https://github.com/TauricResearch/TradingAgents)（87K⭐）：多智能体金融交易框架
- [shareAI-lab/learn-claude-code](https://github.com/shareAI-lab/learn-claude-code)（67K⭐）："Bash is all you need"，从 0 到 1 手搓 nano Claude Code，年度最佳教学仓库之一

## 📄 论文与评测

- **长任务评测**成为新焦点：GAIA、METR 等"端到端任务成功率"指标取代单轮问答，成为产品宣传的新标配
- **多智能体协作**：研究显示 MAS 编排可将复杂任务完成度大幅提升（部分场景 10 倍量级）；管道式/辩论式/分层式/市场式四种架构各有适用场景（手册[第 13 章](../chapters/13-collaboration-patterns.md)有详解）
