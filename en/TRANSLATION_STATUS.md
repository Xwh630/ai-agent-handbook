## 🤝 How to Contribute a Translation

1. Read the Chinese chapter at `../chapters/`
2. Create the English file at `chapters/<same-name>.md`
3. Update this status page (mark ✅)
4. Open a PR

**Translation tips:**
- Keep code blocks unchanged (only translate comments if helpful)
- Keep Mermaid diagrams unchanged
- Use plain, beginner-friendly English
- Link to other English chapters with relative paths
