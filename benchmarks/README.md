# 🩺 Harness 体检榜

> 用 [`agent-handbook doctor`](../src/agent_handbook/doctor.py)（第 [25 章](../chapters/25-harness-engineering.md) 的可执行版本）
> 给知名开源 Agent 项目做静态体检，看它们的五根柱子齐了几根。
>
> **这是一张方法论自检表，不是项目质量排名。** 打分器只做正则静态扫描，看不见运行时行为，
> 也看不见用 TypeScript / Go 写的项目——它衡量的是「代码里有没有这些工程痕迹」。

---

## 怎么读这张表

| 分数 | 含义 |
|---|---|
| 9–10 | 五根柱子都在，且每根都有多处在代码里落地 |
| 6–8 | 能跑，但有 1–2 根偏薄 |
| 3–5 | 原型水平：演示很顺，跑久了会出事 |
| 0–2 | 裸 Agent：崩溃 / 超预算 / 越权全靠运气 |

**为什么这张表值得看**：绝大多数「Agent 跑不稳」不是模型不行，而是这五根柱子少了几根。
同一个模型，Harness 完整度不同，生产表现可以差出数量级。

## 复盘：这一版打分器饱和了，而且这是个有用的结果

平均 **9.6/10**，八个样本里六个满分。作为「排名」这张表毫无信息量——所以下面这三条比表格本身值钱：

**1. 饱和的原因是真实的：五根柱子已经是成熟项目的标配。**
只要仓库里任何位置出现两个不同的实现痕迹，打分器就给满。而 3000 个 Python 文件里凑出两个重试关键词，几乎不可能失败。
换句话说：**在「有没有」这一层，行业已经卷完了。** 这条对读者反而是好消息——你的项目拿 3 分，不是因为你落后于行业平均水平，而是因为你还没开始建。

**2. 只扫文件名和关键词，看不见「接没接上」。**
OpenHands 只扫到 12 个 py 文件（主仓已大面积转向别的语言/结构），Claude Agent SDK 只有 54 个——一个 54 文件的 SDK 和一个 3339 文件的应用拿同分，说明这个口径本身没有区分度。

**3. 下一版打分器只扫「Agent 主循环」。**
判定条件：一个文件里同时出现 LLM 调用与工具分发，才算主循环文件；只扫这些文件里的五根柱子。纯 SDK / 框架直接标「不适用」而不是给分。
这样分数才回答真问题：**你的主循环有没有被这五根柱子包住**，而不是「你仓库里有没有出现过 `retry` 这个词」。

> 这一版就先留着当基线：它至少证明了 `doctor` 能在大仓库上跑完、能稳定复现、能把「框架」和「应用」混在一起时暴露口径问题。等主循环口径上线，再发正式榜单。

## 三个必须写进正文的观察

跑完之后，不要只贴表。**表格本身不传播，表格里的反常识才传播。** 至少回答这三个问题：

1. **分数分布是什么形状？** 如果大多数项目落在 2–5 分，那么"3 分"就是行业常态，而不是读者自己差——这一句能救很多人。
2. **哪根柱子集体缺失？** 预判是「失败恢复」和「权限体系」——因为它们不影响 demo，只影响事故。若成立，这就是全文的核心论点。
3. **有没有高星项目反而低分？** 如果有，这是最有传播力的一条，但**必须写得体**：解释它为什么不需要（比如它只是 SDK/框架，脚手架不该由它负责），而不是嘲讽。

## 伦理约束（重要）

给别人的项目打分，有三条底线：

1. **只描述代码，不评价团队。** 写「未见失败恢复分支」，不写「作者不懂工程」。
2. **承认工具边界。** 每次发结论都带上那句：静态扫描看不见运行时，也看不见非 Python 项目。
3. **先私信，再公开。** 对低分项目，**先给维护者开一条 issue 或私信**说明来意并附上改进建议；
   等对方回应（哪怕是"不需要"）再公开发布。**不要用别人的仓库当你的流量燃料。**

> 这条约束不是道德洁癖，是长期主义：公开打分者一旦被贴上"蹭热度"的标签，
> 这个栏目的价值就归零了。

## 发布节奏

| 时间 | 动作 |
|---|---|
| 第 1 周 | 跑 20–30 个仓库，出首版榜单 + 一张长图 |
| 第 1 周 | 给 5 个低分项目提善意 issue/PR（附 `--md` 输出 + 具体补法） |
| 第 2 周 | 长文发掘金 / 知乎 / V2EX，标题用结论不用栏目名 |
| 每周 | 新增 3–5 个项目，出一期「榜单单品」进 Radar |

标题参考（用结论，不用"我做了个榜单"）：

- 《我扫了 30 个开源 Agent 项目，平均分 3.1/10，最缺的一根柱子是"失败恢复"》
- 《同样用 GPT-5，为什么有的 Agent 能上生产，有的一崩就全崩》
- 《你的 Agent 缺的不是模型，是这五根柱子——附 30 个真实项目的分数》
