## 计划内容

第 19 章将聚焦于 **Agent 通用工具箱**——那些无论你用什么框架都能用上的"瑞士军刀"型工具与实践模式。

### 拟覆盖主题

| 模块 | 说明 |
|------|------|
| 🔧 工具注册中心 | 统一管理工具元数据、权限、限流 |
| 📋 任务队列集成 | Celery / BullMQ 与 Agent 的结合模式 |
| 🔐 审批网关 | Human-in-the-Loop 的标准化实现 |
| 📊 成本追踪器 | 按 Agent/任务/工具维度的 token 计费 |
| 🧪 回放与重放 | 基于轨迹的调试与回归测试 |
| 🛡️ Guardrail 工具集 | 输入过滤、输出校验、越权检测 |

## 为什么是第 19 章？

原目录在第 18 章（选型决策树）和第 20 章（Codex CLI）之间存在编号断层。

选择在此处插入「通用工具箱」而非留空，是因为：
1. **承上启下**：第 18 章讲完选型，接下来自然是"选完框架后，有哪些通用工具"
2. **框架无关**：工具箱内容不绑定任何特定框架，适合放在"框架篇"与"工具篇"之间
3. **扩展空间**：工具箱是持续增长的类别，预留编号方便后续增补
